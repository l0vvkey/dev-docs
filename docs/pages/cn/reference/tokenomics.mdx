# 代币经济学

STABLE 是 Stable 主网的治理代币。它通过委托权益证明来保护网络，管理协议升级，并使质押者有权获得由验证者分配的 USDT0 燃气费收入份额。

## 概述

| 项目 | 详情 |
| :---- | :---- |
| **符号** | STABLE |
| **总供应量** | 100,000,000,000 代币 |
| **标准** | ERC-20 (在 Stable 主网 EVM 上) |
| **小数位数** | 18 |

STABLE 是 Stable 主网和生态系统的治理代币，旨在支持验证者、开发者和用户之间的长期经济一致性。
## 代币分配

**总供应量：** 100,000,000,000 STABLE 代币

| 类别 | 分配比例 | STABLE 数量 |
| :---- | :---- | :---- |
| **投资者与顾问** | 25% | 25,000,000,000 |
| **团队** | 25% | 25,000,000,000 |
| **生态系统与社区** | 40% | 40,000,000,000 |
| **创世分配** | 10% | 10,000,000,000 |
| **总计** | 100% | 100,000,000,000 |

## 发行模型与供应时间表

* 总供应量固定为 100,000,000,000 STABLE 代币。
* 在 Stable 主网启动时，只有一部分供应量进入流通。
* 团队以及投资者与顾问的分配受 STABLE 通用锁管理，旨在确保长期承诺。在 2027 年 12 月 8 日之前，不释放任何锁定代币；此后，锁定代币将在七个预定地板上每天线性释放，并受 VWAP 价格保护机制的约束。

## 分配情况

### 创世分配 - 占代币总供应量的 10%

* 旨在启动使用，为市场提供流动性，进行空投活动，奖励早期支持者以及与交易所和生态系统合作伙伴的活动。

    **归属时间表**
    * 在 Stable 主网启动时 100% 解锁

### 生态系统与社区 - 占代币总供应量的 40%

支持长期生态系统和社区增长：

* 支持 Stable 软件和生态系统的开发
* 开发者资助
* 用户入驻激励
* 支付合作伙伴集成
* 链上活动奖励
* 黑客马拉松、大使计划
* 基础设施资助

  **归属时间表**
  * **初始解锁：** Stable 主网启动时解锁总供应量的 8%。这些代币用于资助战略启动合作伙伴的激励、流动性需求和早期生态系统增长活动。

分配给生态系统和社区的剩余 32% 总供应量受 STABLE 通用锁管理。在 2027 年 12 月 8 日之前，不释放任何锁定代币；此后，锁定代币将在七个预定地板上每天线性释放，并受 VWAP 价格保护机制的约束。在 TGE 时解锁的初始 8% 不受通用锁的限制。

### 团队 - 占代币总供应量的 25%

* 分配给创始团队成员、工程师、研究员和贡献者
* 旨在确保团队与 Stable 生态系统之间的长期一致性。

    **归属时间表**
    * **2 年锁定期：** 受 STABLE 通用锁管理。在 2027 年 12 月 8 日之前，不释放任何锁定代币；此后，锁定代币将在七个预定地板上每天线性释放，并受 VWAP 价格保护机制的约束。

### 投资者与顾问 - 占代币总供应量的 25%

* 分配用于融资轮次和咨询支持。

    **归属时间表**
    * **2 年锁定期：** 受 STABLE 通用锁管理。在 2027 年 12 月 8 日之前，不释放任何锁定代币；此后，锁定代币将在七个预定地板上每天线性释放，并受 VWAP 价格保护机制的约束。

## 经济设计原则

Stable 的代币经济学围绕三个基本目标设计：

### 1. 为支付优化的 Layer 1 提供动力

STABLE 代币激励高吞吐量、低延迟的基础设施，支持亚秒级区块确认和企业结算保障。

### 2. 支持可持续的生态系统增长

40% 的代币总供应量用于长期增长，重点关注关键开发和增长领域。

* 开发者资助
* 合作伙伴集成
* 新的生态系统应用

### 3. 通过归属使长期贡献者保持一致

团队分配受 STABLE 通用锁管理，确保长期一致性并持续为网络开发做出贡献。

## STABLE 代币的用途

STABLE 代币是 Stable 主网上的 ERC-20 治理代币。它可以用于：

* 选举验证者
* 对协议升级进行投票
* 处理治理提案
* 作为接收验证者燃气费分配的凭证

在 Stable 网络上，所有交易都使用 USDT0 作为原生燃气代币。这些 USDT0 燃气费被收集到一个由智能合约管理的资金库中。当代币持有者将他们的 STABLE 代币质押给验证者时，验证者可以选择按比例向质押者分配资金库中的燃气费。
